# 🐘 SQL Middle Academy — PostgreSQL

Интерактивный сайт для изучения SQL: от **junior** до **senior**, со стандартом **PostgreSQL**.
Всё работает локально, без внешней СУБД: запросы выполняет **PGlite** — настоящий
PostgreSQL 18.6, скомпилированный в WebAssembly и запущенный прямо внутри Node.js.

## Что внутри

| Раздел | Что умеет |
| --- | --- |
| 📚 **База знаний** | **34 модуля** по уровням **Junior / Middle / Senior**: от основ и типов данных до планировщика, MVCC, партиционирования, PL/pgSQL и безопасности. Фильтр по уровню, группировка, примеры SQL с кнопкой «в песочницу» |
| 🎯 **Тренажёр** | **42 задачи** с сюжетными условиями: бизнес-контекст, нюансы и явное «Выведите …» с описанием каждой колонки. Подсказки, эталонные решения, проверка результата, прогресс, фильтр по уровню |
| 🧪 **Песочница** | Свободные запросы (несколько команд через `;`), выбор набора данных, сброс к исходному состоянию, схема рядом |
| 📖 **Справочник** | Полный каталог: операторы, агрегатные и оконные функции, строки, математика, даты, JSON, массивы, FTS, DDL/DML, транзакции, индексы, безопасность, PL/pgSQL, EXPLAIN — с глобальным поиском |
| 🗄️ **Схема БД** | Структура учебных баз данных |

## Уровни

- **Junior** — реляционная модель, типы, SELECT, фильтрация, агрегация, JOIN, подзапросы, CASE, DML, ограничения, даты.
- **Middle** — оконные функции, CTE и рекурсия, множественные операции, JSON/JSONB, массивы, индексы и EXPLAIN, транзакции, представления, UPSERT, строки/regexp, SQL-паттерны.
- **Senior** — планировщик, продвинутые индексы, MVCC/VACUUM, блокировки, партиционирование, полнотекстовый поиск, PL/pgSQL и триггеры, безопасность и RLS, мониторинг, архитектура (WAL, репликация, бэкапы), моделирование данных, продвинутый SQL (GROUPING SETS, LATERAL, DISTINCT ON).

## Учебные базы данных

1. **Компания (HR)** — `departments`, `employees`, `projects`, `employee_projects`.
   Есть JSON-поле `meta`, массив `skills`, даты найма, иерархия руководителей.
2. **Магазин (E-commerce)** — `customers`, `products`, `orders`, `order_items`.

## Запуск

```bash
npm install      # зависимости уже установлены
npm start        # сервер на http://localhost:4000
```

Откройте **http://localhost:4000**.

## Доступ с телефона и из интернета

- **Дома / в той же сети:** `http://192.168.1.6:4000` (сервер слушает все интерфейсы).
- **Из любой сети (мобильный интернет, другое место):** публичный туннель.

Запуск публичного доступа:

```bat
start-public.bat
```

Скрипт поднимает сервер и SSH-туннель `localhost.run`; в окне туннеля
печатается адрес вида `https://xxxxxxxx.lhr.life` — его и открывайте на телефоне.

Важно:
- Компьютер должен быть включён, окна сервера и туннеля — открыты.
- Бесплатный временный адрес меняется после перезапуска туннеля.
- Для постоянного адреса — аккаунт на `admin.localhost.run` или хостинг.
- Проброс порта в брандмауэре не нужен: туннель работает через исходящее SSH-соединение.
- Интерфейс адаптирован под телефон (одна колонка, крупные кнопки, скроллируемое меню).

## GitHub Pages (статическая версия)

Папка [`docs/`](docs/) — **полностью статическая** сборка: PostgreSQL (PGlite)
выполняется в браузере, сервер не нужен. Её можно бесплатно и навсегда
опубликовать на GitHub Pages.

Пошаговая инструкция: [DEPLOY-PAGES.md](DEPLOY-PAGES.md).

Кратко: создайте репозиторий, запушьте проект, затем **Settings → Pages →
Source: Deploy from a branch → main → /docs**.

Особенность: при первом открытии браузер скачивает WASM PostgreSQL (~15–20 МБ),
дальше он кэшируется. Все запросы (тренажёр, песочница, справочник) выполняются
локально, без сети.

## Структура проекта

```
server/
  index.js            # Express-сервер и REST API
  engine.js           # движок PGlite: инстансы, транзакции, сравнение результатов
  data/
    schema.js         # схемы БД и seed-данные
    lessons.js        # объединяет уровни
    lessons-junior.js # 10 модулей (junior)
    lessons-middle.js # 12 модулей (middle)
    lessons-senior.js # 12 модулей (senior)
    tasks.js          # 42 задачи тренажёра
    reference.js      # полный справочник
public/
  index.html          # SPA
  styles.css          # тёмная тема
  app.js              # фронтенд (роутер, CodeMirror, рендер)
  vendor/codemirror/  # CodeMirror 5
test-tasks.mjs        # проверка всех эталонных запросов задач
```

## Технологии

- **Node.js + Express** — сервер и REST API
- **PGlite** — PostgreSQL 18 в WebAssembly (оконные функции, JSON/JSONB, массивы, рекурсивные CTE, EXPLAIN и т.д.)
- **CodeMirror 5** — редактор с подсветкой SQL и автодополнением

## Проверка задач

```bash
node test-tasks.mjs
```

Выполняет эталонные запросы всех задач (каждый — в транзакции с откатом) и выводит результат.

## Горячие клавиши редактора

- `Ctrl+Enter` — выполнить запрос
- `Ctrl+Space` — автодополнение (таблицы и колонки)
- `Ctrl+/` — закомментировать строку
